# 13. 场景构造公式

历史日 `s`：

```python
target_forecast_kw
    = 目标日当前issue的最新插值预测

historical_error_kw
    = 历史日s同issue的预测误差

pv_scenario_kw
    = np.maximum(
        target_forecast_kw
        + historical_error_kw,
        0.0,
    )

load_scenario_kw
    = 历史日s同时间位置实际负载

net_load_scenario_kwh
    = (
        load_scenario_kw
        - pv_scenario_kw
    ) * DT_HOURS
```

概率：

```python
probability = np.full(
    31,
    1.0 / 31.0,
)
```

不要把不同日期的负载和光伏预测误差随机重配。

# 19. 调整费用口径

配置：

```python
UP_ADJUST_PRICE_MULTIPLIER = 1.5
CANCEL_REFUND_MULTIPLIER = 0.5
```

一次调整现金流：

```python
adjustment_cashflow = (
    np.dot(
        1.5 * price_remaining,
        up_adjust,
    )
    -
    np.dot(
        0.5 * price_remaining,
        down_adjust,
    )
)
```

负号代表减少合同量可收回计划电价的 50%，取消部分实际损失另外 50%。


# 28. `revise()`伪代码

```python
def revise(state, issue_hour):
    start = ISSUE_SLOT[issue_hour]

    current_soc = get_boundary_soc(
        state,
        start,
    )

    old_grid = state.current_grid[start:]

    scenarios = build_rolling_scenarios(
        target_date=state.date,
        issue_hour=issue_hour,
    )

    result = solve_adjustment(
        old_grid=old_grid,
        current_soc=current_soc,
        scenarios=scenarios,
    )

    state.revision_logs.append(result.revision)

    state.current_grid[start:] = result.new_grid
    state.current_charge[start:] = result.charge
    state.current_discharge[start:] = result.discharge
```
